# Human Error

人間には伝わるが、学習するAIには伝わらない絵を描く、
協力型お絵描きパーティーゲームです。

## Members

- Flora: Frontend / UI / Visual Design
- Subat: Backend / AI / Game System

## Project Structure

- `frontend/`: User interface and drawing system
- `backend/`: Python server, game rules and AI
- `shared/`: API specification and shared game data
- `tests/`: Automated tests

## Development Rules

- `main` contains the stable version.
- Flora works mainly on `flora/frontend`.
- Subat works mainly on `subat/backend`.
- Changes are merged through Pull Requests.
